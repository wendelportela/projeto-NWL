# 🚀 Projeto NLW

Projeto desenvolvido durante o evento **Next Level Week (NLW)** da Rocketseat, com o objetivo de praticar desenvolvimento web e aplicar conceitos modernos de programação.

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático da **NLW**, onde a proposta é construir uma aplicação funcional utilizando tecnologias atuais do ecossistema web.

O objetivo principal foi reforçar conhecimentos em desenvolvimento front-end e boas práticas de organização de código.

## 🛠️ Tecnologias utilizadas

As principais tecnologias utilizadas no projeto foram:

- HTML
- CSS
- JavaScript
- Git
- GitHub

## 📂 Estrutura do projeto

A estrutura do projeto foi organizada para facilitar a manutenção e entendimento do código:

┣ 📂 assets
┣ 📂 css
┣ 📂 js
┣ 📄 index.html
┗ 📄 README.md
